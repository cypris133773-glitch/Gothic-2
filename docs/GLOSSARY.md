# Glossary

Every proper noun in GRIMWARD, and the concept from the tradition it answers to.
When a name is needed that is not here, invent one in the same phonology — hard
consonants, short vowels, Old-Germanic — and add it in the same commit.

## The world

| Name | What it is |
| --- | --- |
| **Verath** | The island. Everything happens here. |
| **Halden** | The walled port city. Forty named residents, six traders, five trainers. |
| **The Vale** | Farmland, road, mill, forest edge. The tutorial that is not a tutorial. |
| **The Drowned Coast** | Cliffs, ruins, a pirate cove. Optional, opens in chapter 2. |
| **The Cleft** | The ore valley. Enterable from the first hour; will kill you for most of them. |
| **the Ward** | The magical containment that held the old penal colony, collapsed a year before the game opens. |

## The gods

| Name | Domain |
| --- | --- |
| **Aurin** | Fire, law, the sun. The state religion, and the one with an army. |
| **Meren** | Water, balance, the tide. Older, quieter, and the one the ruins belong to. |
| **Skarn** | Dark, entropy, the worm under the mountain. Not worshipped so much as bargained with. |

## The guilds

Three, mutually exclusive. Joining one closes the other two permanently.

| Name | Path |
| --- | --- |
| **the Watch** | City militia → **Sunblades**, the mainland order that arrives in chapter 2. Heavy armour, shields, law. |
| **the Ember Chapter** | Novice → **Emberwarden**. The only path to runes and the six circles. |
| **Freeblades** | Mercenaries in the Vale → **Wyrmhunters** when the dragons come. Two-handers and no rules. |
| **Tidecutters** | Pirates of the Drowned Coast. Not a joinable guild; a faction you can be owed by. |

## People

| Name | Who |
| --- | --- |
| **the Warden's Man** | The player. Unvoiced; the player names him. |
| **Ossric** | The necromancer in the tower on the ridge. Knows what the dragons are for. |
| **Harl** | Halden's smith. Trains one-handed to 45% for anyone who earns it. |
| **Bosk** | Hunter in the Vale. His brother did not come back from the north wood. |

## Things

| Name | What |
| --- | --- |
| **blackore** | The only metal that bites a dragon. Cannot be bought. |
| **carrion-runner** | Scavenging pack bird. The first thing that kills a new character. |
| **delver** | Burrowing rodent, surfaces under you. |
| **ripper** | Two-legged pack predator of the river gorge. |
| **shadeclaw** | The forest at night, with teeth. Do not fight two. |
| **the Vharn** | Clan-organised orcs of the Cleft. Disciplined, not comic. |
